# Contributing

Thanks for considering a contribution!

## Ways to help

- Fix typos or improve explanations.
- Suggest accessibility improvements.
- Test the page on mobile and desktop.
- Propose dimension updates with a link to the platform's official documentation.
- Improve keyboard navigation or screen-reader support.

## Before opening a pull request

1. Keep changes focused and explain why they are useful.
2. Verify any platform dimensions against an official source.
3. Do not add assets unless you created them or have permission to redistribute them.
4. Test `index.html` in a browser at desktop and mobile widths.
5. Describe what you changed and how you tested it.

For larger changes, open an issue first to discuss the idea.
