# Social Media Design Kit

A beginner-friendly, open-source reference for common social media design dimensions and practical design tips.

## What's included

- A responsive webpage listing commonly used post dimensions
- Quick-copy dimension labels
- A short checklist for making clear, accessible social graphics
- Beginner-friendly documentation for contributors

## Run it locally

No installation or build tools are required.

1. Download or clone this repository.
2. Open `index.html` in a web browser.

## Project status

This is an initial educational project. Platform specifications can change, so verify dimensions against each platform's official documentation before using them in client work.
